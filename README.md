# Portal-Conserto
Acompanhe o status do seu material em manutenção: nesta plataforma, você visualiza desde a fase de Recebimento e Triagem — onde confirmamos a chegada do equipamento e avaliamos o defeito informado — até a Liberação após Reparo, que indica que o conserto foi concluído com sucesso, os testes de qualidade foram aprovados e o item já está pronto.
